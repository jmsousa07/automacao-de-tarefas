# Automação de Cadastro de Produtos com Selenium

Projeto desenvolvido para fins de estudo e portfólio, com foco em automação web utilizando Python e Selenium.

## Funcionalidades
- Login automatizado
- Leitura de produtos via CSV
- Cadastro automático de produtos
- Tratamento de exceções por produto
- Registro de logs de execução

## Tecnologias
- Python
- Selenium WebDriver
- Page Object Model (POM)

## Estrutura do Projeto
- pages: páginas do sistema
- utils: utilidades e infraestrutura
- data: dados de entrada
- logs: histórico de execução

## Como executar
1. Instale as dependências
2. Execute `python main.py`
